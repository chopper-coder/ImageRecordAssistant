## Environment limitation

A full real-decoder browser benchmark using the pinned `heic-to 1.5.2` module could not be completed in this build environment: external npm installation timed out and the managed Chromium instance blocks local/file navigation. Therefore this report does **not** claim a measured real-device speed-up percentage.

The release does verify the actual scheduling logic (parallelism, persistence, single native probe and cancellation) and keeps the GitHub Pages workflow responsible for installing the pinned runtime decoder during deployment.
