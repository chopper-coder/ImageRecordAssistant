# 圖片紀錄整理助手 V3.8.5

**Audit Log Quick Access Hotfix**

大量照片整理、HEIC/HEIF 匯入、照片說明/地點、裁切旋轉、註記與個資遮蔽、章節分類、暫存續編、Word/PDF 輸出等功能皆在瀏覽器本機處理。

## V3.8.5 新增：操作紀錄與稽核追蹤

在「更多工具與專案管理」中新增 **操作紀錄與稽核追蹤**：

- 自動記錄重要操作時間與類型。
- 顯示最近 8 筆操作與目前總筆數。
- 支援匯出 **TXT / CSV / JSON**。
- 操作紀錄會隨 IndexedDB 自動儲存、手動暫存與 `.photojob` 保存。
- `.photojob` 的既有 SHA-256 `project.json` 完整性驗證會一併涵蓋操作紀錄。
- 最多保存 1,500 筆，超過後保留最新紀錄，避免專案中繼資料無限制膨脹。
- CSV 對 `= + - @` 開頭欄位做公式注入防護。

### 會記錄哪些動作

包含照片匯入／失敗重試、單張與批次重新命名、旋轉、裁切、註記、批次說明／地點／章節、排除輸出、Undo/Redo、健康檢查、封存、暫存／續編、`.photojob` 開啟與儲存、列印預覽、Word/PDF 輸出等重要工作節點。

為降低不必要的敏感資料複製，**操作項目不會把單張照片說明、備註或照片地點全文再寫進紀錄**；匯出 TXT/JSON 的表頭仍會列出目前案件的基本資料與照片數量。

> 操作紀錄是本機工作追蹤與稽核輔助資料，不是不可竄改、具法律證據效力的電子稽核系統。使用者仍可清除紀錄；清除後程式會保留一筆「清除操作紀錄」提示事件。

## V3.8.3 保留功能：暫存工作階段

- **暫存目前工作**：立即把目前專案寫入本機 IndexedDB。
- **繼續上次暫存**：同一瀏覽器下次開啟後可接著整理。
- **清除暫存**：只清除手動暫存標記，不刪目前畫面內容。
- 暫存沿用同一份 IndexedDB 專案快照，不會另外複製整套照片造成容量翻倍。

暫存只存在目前瀏覽器／裝置；跨電腦或正式備份仍請使用 `.photojob`。
